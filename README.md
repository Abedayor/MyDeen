# 📖 MyDeen – Qur'an, Arabic Learning & Tajweed Web App

**MyDeen** is a web application designed to help users **read, understand, and listen** to the **Qur’an**, **learn Arabic**, and **master Tajweed rules**.

## 🌟 Main Features

### 📚 Qur'an Reading
- Browse all **114 Surahs**
- Display of each verse with:
  - **Arabic text** (Mushaf style)
  - **French translation**
  - Numbered verse markers (circular icons)
- Dynamic rendering of verses (via embedded data or external API)

### 🔊 Audio Playback
- Listen to Surah recitations
- Custom audio controls:
  - Play / Pause
  - Skip forward/backward by 3 seconds
  - Progress bar
  - Close button to hide audio bar

### 🧠 Arabic Learning
- Learn the **Arabic alphabet**
- Pronunciation with examples and phonetics
- Interactive recognition exercises

### 🎙️ Tajweed Module
- Introduction to **Tajweed rules**
- Clear explanations of concepts (Ikhfa’, Idgham, Qalqalah, etc.)
- Practical application using Qur’anic examples

## 🎯 Goals
- Provide **easy access** to Qur’anic content with a clean and user-friendly interface
- Support **beginners** in learning **Modern Standard Arabic**
- Assist users in learning **proper Qur’anic recitation** (Tajweed)

## 🛠️ Tech Stack
- **HTML / CSS / JavaScript**
- Fully dynamic interface (no frameworks)
- Native HTML5 audio support
- Integration with Qur'an API (e.g. Qur’an Cloud) or manual verse data
  
## 🚧 Upcoming Features

- **Favorites** system for saving verses
- **Dark mode**
- **Interactive quizzes**
- Partial **offline access**
